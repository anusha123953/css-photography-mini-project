# 📸 CSS Photography Mini Project

A photography-themed webpage created using HTML and CSS.

## 🚀 Features

- Sidebar navigation menu
- Font Awesome icons
- Image display and styling
- Hover effects
- CSS positioning
- Flexbox layout
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📂 Project Structure

```text
css-photography-mini-project/
├── index.html
├── style.css
├── photo.jpg
└── README.md
```

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

## 📚 What I Learned

- Connecting HTML with an external CSS file
- Styling a sidebar navigation menu
- Using CSS positioning and Flexbox
- Adding icons using Font Awesome
- Displaying and styling images
- Applying hover effects
